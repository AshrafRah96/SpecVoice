# First Session

Complete [local setup](../README.md#local-setup). Use private dashboard:

1. Sign in; enter repository URL. Session pins commit; profiling runs asynchronously.
2. Wait for ready or partial profile. Start private web call; permit microphone. Initial acceptance: one bounded change, synthetic content.
3. Review file evidence, decisions and open questions. Request Spec; resolve questions before Build.
4. Edit/save included/excluded literal paths. Confirm required Scope Plan. Changed proposal needs fresh confirmation.
5. End call; wait for signed callback. Builds stay blocked during active calls or pending transcripts.
6. Select **Build It**. Worker runs one attempt at a time: disposable container, permitted-change validation, draft PR.
7. Review diff and tests before merge. Reopen Session through URL or history to continue planning.

Calls last at most 45 minutes; another call continues the same Session. Expired profiles rebuild at original commit. Recovery-only retry finishes publication without model generation. Missing output needs explicit new Build.

Checks, spend limits, recovery: [Evaluation](evaluation.md), [Build pipeline](build-pipeline.md), [Backups](backups.md).
